# Portfolio Website

Website **portfolio developer** personal — menampilkan profil, keahlian, dan project. Dibangun dengan HTML, CSS, dan JavaScript.

## ✨ Fitur
- Halaman profil & perkenalan
- Showcase project & keahlian
- Desain responsif

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript

## 🚀 Menjalankan
Buka `index.html` di browser, atau jalankan server statis:
```bash
npx serve .
```

## 📄 Lisensi
Dibuat untuk keperluan pembelajaran.
