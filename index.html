About 01

Not just writing code — shaping experiences that people actually want to use.

I am Leo Alfonso Tarigan, a developer who believes great software starts with genuine curiosity. Currently pursuing Computer Science at the University of North Sumatra, I split my time between building full-stack web applications and exploring how machine learning can solve real problems.

Four years ago I wrote my first line of server code. Since then, I have shipped over fifty projects spanning e-commerce platforms, data dashboards, attendance systems, and AI-powered tools — including seikouverse.my.id. Every project taught me something the last one could not.

I gravitate toward the entire stack — database schema to pixel-perfect frontend — because details at every layer compound into software that feels right.
